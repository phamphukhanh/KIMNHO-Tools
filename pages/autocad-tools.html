Hướng Dẫn Cài Đặt Công Cụ Vào AutoCAD

Cách 1: Load nhanh kéo thả

  1. Lưu các file .VLX / .ARX đã tải vào một thư mục cố định trên máy.
  2. Kéo thả trực tiếp: Click giữ file từ thư mục vừa lưu và kéo thả trực tiếp vào không gian bản vẽ AutoCAD đang mở để sử dụng ngay.

Cách 2: Tự động khởi chạy (Khuyên dùng)

  1. Lưu các file .VLX / .ARX đã tải vào một thư mục cố định trên máy.
  2. Trong AutoCAD, gõ lệnh APPLOAD (hoặc gõ tắt AP) nhấn Enter.
  3. Nhấn nút Contents... ở mục Startup Suite (Biểu tượng chiếc cặp).
  4. Nhấn Add..., chọn các file plugin và lưu lại. Công cụ sẽ tự động load mỗi khi mở AutoCAD.
